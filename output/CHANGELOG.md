### 1. 사람 승인 게이트(Gate) 시각 언어 도입
- CSS에 게이트 전용 디자인 시스템 추가: 대기중=주황 점선+🔒, 승인됨=초록 실선+✓ 로 전 화면 통일
  (`.gate-card`, `.gate-badge`, `.gate-block`, `.gate-divider`, `.gate-ribbon`, `.gate-legend`)
- 주문 상세페이지: 5개 검수 카드(CEO결재/시안검수/안전점검/사진대지/서류·세무)를 세로 체인으로 재구성.
  카드 사이에 "🔒 OO 승인 대기 — 다음 단계 진행 불가" 문구가 박힌 pulsing 디바이더 삽입 (모바일에서도 스크롤 없이 보이도록 세로 배치)
- 오피스 6단계 파이프라인 스트립: 막힌 지점만 굵은 주황 STOP 칩으로 확대, 통과 구간은 얇은 초록선으로 축소
  (`overflow-x-auto` → `flex-wrap`으로 좁은 화면 자동 줄바꿈)
- 게이트가 걸리는 직원 카드(원가대리/디자인/공정주임/물류주임/세무주임)에 🔒 리본 배지 + **배경 빨간 깜빡임 애니메이션**(`gateCardBlink`) 추가
- 주문 목록 배지를 `gateBadge()` 헬퍼로 통일
- 사람 확인 알림 모달 탭/요약 카운트에도 동일 🔒/✓ 표기 적용

### 2. 직원카드 "원클릭 빠른 업무 지시" 프리셋 — 실제 기능 연결

  - 디자인 → 시안 미검수 주문 → `openProofModal()`

### 3. 원가 대리(quote) — 견적 산출 실제 카탈로그 연동
- 이전: `banner=450000 / service=300000 / 기타=250000` 하드코딩 3개 값 고정
- 이후: `computeAutoQuote(o)` 헬퍼 신설 — `Store.data.catalog`(조달몰 카탈로그 DB)에서 주문 유형(cat)에 맞는 실제 등록 상품을 조회해 단가·품목명·규격·단위를 가져오고, 주문의 실제 수량(`o.detail.qty`)을 곱해 계산
  - 관리자가 카탈로그 관리 화면에서 단가를 바꾸면 다음 견적부터 즉시 반영됨 (이전엔 카탈로그 단가와 견적 로직이 완전히 분리되어 있었음)

  - 카탈로그에 해당 분야 상품이 없을 때만 예시단가로 대체하고, 그 사실을 화면에 경고로 표시
