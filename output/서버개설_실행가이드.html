서버를 하나 만들어야 하는 이유와, 실제로 만드는 순서

개발 용어 없이 읽을 수 있도록 썼습니다. "서버"는 우리 회사 전용 캐비닛 겸 자동 비서라고 생각하시면 됩니다 — 지금까지는 이게 없어서 못 하던 일들이, 이걸 만들고 나면 됩니다.

01

지금 시스템으로는 안 되는 것들

지금 시스템(공급자_납품사이트.html)은 각자의 컴퓨터 브라우저 안에만 데이터를 저장합니다. 그래서 아래 5가지는 코드를 아무리 잘 짜도 "서버"가 있어야만 진짜로 됩니다.

🖥️ 지금 — 브라우저 혼자 처리

내 컴퓨터에서 접속하면 내 데이터만 보임. 다른 컴퓨터·직원 폰에서 보면 안 보임. 카톡·이메일을 실제로 보내거나 받을 방법이 없음. 사진 용량 5MB 넘으면 저장 자체가 막힘.

→

🗄️ 서버 있을 때 — 회사 공용 창고

어느 기기에서 접속하든 같은 데이터를 봄. 이메일이 오면 자동으로 알아채서 접수를 시작함. 카카오 알림톡·세금계산서를 실제로 발송함. 사진 용량 제한이 사실상 사라짐.

02

전체 그림 — 화면은 그대로, 뒤에 창고 하나가 생기는 것

지금 아임웹에 넣어놓은 화면(주문 넣고, 견적서 보고, 승인 누르는 그 화면)은 그대로 유지됩니다. 사용자·직원 입장에서 보이는 건 안 바뀝니다. 바뀌는 건 "저장하는 곳"과 "이메일·카톡·세금계산서를 실제로 보내는 뒷단"입니다.

지금: 화면 ⇄ 이 컴퓨터의 브라우저 저장소 (localStorage)

서버 있을 때: 화면 ⇄ Supabase(회사 공용 창고) ⇄ 필요할 때만 이메일 자동화·카카오 알림톡·전자세금계산서 세 도우미에게 일을 시킴

03

필요한 것 4가지

전부 회원가입만 하면 바로 쓸 수 있는 기존 서비스입니다. 서버용 컴퓨터를 직접 사서 설치하는 게 아니라, 이미 만들어진 서비스에 우리 회사 계정을 만드는 개념입니다.

🗄️

Supabase

데이터 창고 + 자동화 두뇌

주문·견적·사진·직원 기록을 저장하는 진짜 창고. 지금의 "브라우저 안 저장소"를 대체합니다.

왜 필요: 모든 기기에서 같은 데이터를 보려면 데이터가 한 곳(중앙)에 있어야 합니다.
📧

Zapier (이메일 자동화)

코드 없이 "이메일 오면 알림" 설정

회사 이메일함에 새 메일이 오면 자동으로 시스템에 전달해주는 중계 서비스. 코딩 없이 화면에서 클릭만으로 설정합니다.

왜 필요: 이메일 도착 → 자동 접수 시작을 하려면 누군가 이메일함을 계속 지켜봐야 하는데, 이걸 대신 해줍니다.
💬

카카오 알림톡 대행사

비즈엠·알리고 등 (택1)

카카오톡으로 "접수확인", "납품완료" 같은 정식 알림 메시지를 실제로 보내주는 회사. 카카오와 직접 계약하는 게 아니라 이런 대행사를 거칩니다.

왜 필요: 카카오는 개인이 아닌 회사가 직접 알림톡을 못 보내고, 승인받은 대행사를 통해서만 가능합니다.
🧾

전자세금계산서 대행사

팝빌·바로빌 등 (택1)

국세청 홈택스에 실제로 세금계산서를 발행·전송해주는 서비스. 지금처럼 번호만 임의로 만드는 게 아니라 진짜 국세청 시스템에 등록됩니다.

왜 필요: 세금계산서는 사업자 인증 절차가 있어서, 이런 전문 대행사를 거치는 게 표준적인 방법입니다.
04

누가 무엇을 하나

계정 만들기·계약·비용 결제는 사업자 명의가 필요해서 사장님이 직접 해야 합니다. 그 계정에 연결하는 코드 작업은 제가 합니다.

👤 사장님이 할 일

  • Supabase / Zapier 회원가입 (이메일만 있으면 5분)
  • 카카오 비즈니스 채널 개설 (사업자등록증 필요)
  • 알림톡 대행사 계약 및 발신 비용 충전
  • 전자세금계산서 대행사 가입 (사업자 인증, 공동인증서)
  • 가입 후 발급되는 "키(비밀번호 같은 것)"를 저에게 전달

🛠️ 제가(개발) 할 일

  • Supabase에 주문·견적·직원 데이터 저장 구조 설계
  • 지금 화면이 브라우저 저장소 대신 Supabase를 보도록 코드 수정
  • Zapier 자동화와 시스템을 연결하는 코드 작성
  • 알림톡·세금계산서 대행사 API를 시스템에 연동
  • 전 과정 테스트 및 안전하게 전환
05

예상 비용

아래는 시작 단계에서 흔한 요금제 기준의 대략적인 시세입니다. 실제 대행사 견적·환율·정책 변경에 따라 달라질 수 있어 계약 전 반드시 재확인이 필요합니다.

항목시작 요금제규모 커지면
🗄️ Supabase무료 소규모 데이터면 충분월 $25~ (데이터·트래픽 많아질 때)
📧 Zapier무료 월 100건 자동화월 $19.99~ (건수 늘어나면)
💬 카카오 알림톡발신 1건당 약 15~20원 내외월 발송량에 비례
🧾 전자세금계산서발행 1건당 약 100~200원 내외월 발행량에 비례

즉, 지금 당장 큰돈이 들지 않습니다 — Supabase·Zapier는 무료로 시작 가능하고, 카카오·세금계산서는 실제 보낸 건수만큼만 소액이 나갑니다. 목돈이 들어가는 건 이 단계가 아니라 "제가 코드를 연결하는 작업 시간"입니다.

06

실행 순서

한 번에 다 하지 않고, 위험이 적은 것부터 순서대로 하나씩 켭니다. 이전 단계가 잘 되는 걸 확인하고 다음으로 넘어갑니다.

1

Supabase 계정·프로젝트 생성약 30분

이메일로 가입하고 "프로젝트"라는 걸 하나 만듭니다. 이게 우리 회사 전용 창고의 주소가 됩니다.

사장님: 가입저: 설정값 확인
2

데이터 이전 — 브라우저 저장소 → 창고로 이사2~3일 작업

지금 주문·견적·직원 데이터 구조를 창고에 옮기고, 화면이 창고를 보고 동작하도록 코드를 바꿉니다. 이 단계가 끝나면 다른 컴퓨터에서 접속해도 같은 데이터가 보입니다.

전부 저
3

이메일 자동 접수 연결약 1일

Zapier에 회사 이메일을 연결하고, "새 메일 오면 시스템에 전달"이라는 규칙 하나만 만듭니다. 이제 이메일이 오면 사람이 열어보지 않아도 접수 화면에 자동으로 뜹니다.

사장님: Zapier 가입, 메일함 연결 허용저: 연결 코드
4

카카오 알림톡 신청·연동3~5 영업일 (승인 대기 포함)

비즈니스 채널을 열고 대행사와 계약한 뒤, "접수확인", "납품완료" 같은 문구를 미리 등록해서 카카오 승인을 받습니다. 승인이 나면 실제 발송이 가능해집니다.

사장님: 채널 개설·계약·문구 승인 신청저: 연동 코드
5

전자세금계산서 연동2~4 영업일

대행사에 사업자 인증을 마치면, 시스템에서 "발행" 버튼을 눌렀을 때 진짜 국세청에 세금계산서가 등록되도록 연결합니다.

사장님: 가입·사업자 인증저: 연동 코드
6

테스트 & 전환2~3일

가짜 주문 몇 건으로 접수→견적→승인→알림톡→세금계산서까지 전 과정을 실제로 돌려보고, 문제가 없으면 실제 운영으로 전환합니다. 아임웹에 넣어둔 화면 주소는 바뀌지 않습니다.

사장님: 최종 확인저: 테스트 진행
07

자주 하는 걱정

지금 쓰던 데이터(기존 주문 내역)가 사라지나요?
아닙니다. 2단계(데이터 이전)에서 지금 브라우저에 있는 데이터를 그대로 창고로 옮깁니다. 옮기기 전에 항상 백업(output 폴더 방식과 동일)을 먼저 남깁니다.
전환하는 동안 시스템을 못 쓰나요?
1~5단계는 기존 화면과 별개로 준비되고, 6단계 테스트가 끝난 뒤에만 실제로 전환합니다. 준비 기간 중에는 지금 쓰던 방식 그대로 계속 쓰실 수 있습니다.
개인정보(공무원 이름·연락처)가 안전한가요?
Supabase는 데이터를 암호화해서 저장하고 비밀번호로 접근을 통제합니다. 다만 "누가 어떤 데이터를 볼 수 있는지" 권한 설정은 반드시 저와 함께 검토해야 하는 부분이라, 2단계에서 별도로 확인해드리겠습니다.
나중에 마음이 바뀌면 되돌릴 수 있나요?
네. 창고(Supabase)에 있는 데이터는 언제든 다시 파일로 내려받을 수 있고, 각 서비스는 언제든 해지 가능합니다. 회사 자산(주문·견적 데이터)이 특정 서비스에 갇히지 않도록 설계합니다.
왜 한꺼번에 하나의 "우리 서버"를 사서 직접 설치하지 않나요?
직접 서버 컴퓨터를 사서 운영하려면 보안 관리·정전 대비·소프트웨어 업데이트를 계속 사람이 해야 합니다. Supabase 같은 서비스는 그런 관리를 대신 해주기 때문에, 비개발자가 있는 소규모 사업장에는 훨씬 안전하고 저렴합니다.

    이메일만 있으면 됩니다. 가입 후 "프로젝트 이름"만 저에게 알려주시면 나머지는 제가 설정합니다.

  • 전자세금계산서 대행사 1곳 결정
    팝빌·바로빌 중 기존에 거래·회계 프로그램에서 이미 쓰고 있는 곳이 있다면 그쪽으로 맞추는 게 제일 간편합니다.
