01

실제 구현에 필요한 준비 자료

아래 5가지는 코드로 대신할 수 없는, 회사(제천종합공급유통)에서 직접 확정·전달해야 하는 자료입니다. 자료가 도착하는 순서대로 해당 기능을 실제 데이터로 교체합니다.

  • 품목별 실제 단가표 필수
    현재 조달몰 카탈로그 8개 품목은 데모 가격입니다. 원가 대리(정확이)의 자동 견적이 이 표를 그대로 읽어 견적서에 반영하므로, 실제 청구 가능한 단가가 아니면 견적 자체가 무효가 됩니다.
  • 회사 사업자 정보 확정 필수
    상호·사업자번호·대표자·주소·계좌가 견적서·납품서 상단에 그대로 인쇄됩니다. 현재 값(제천종합공급유통 / 307-81-12345)이 실제 정보인지 확인이 필요합니다.
  • 제천시 CI 로고 · 슬로건 파일 시안 품질
    디자인 선임(창의)의 시안이 지금은 텍스트뿐입니다. 로고 SVG/PNG와 색상 가이드가 있으면 ⑤ 섹션의 목업 수준을 훨씬 실제 시안에 가깝게 올릴 수 있습니다.
  • 관공서 지정 서식 여부 확인 확인 필요
    지금 견적서·납품서는 시스템이 자체 제작한 양식입니다. 제천시청 회계과가 별도 지정 양식을 요구하는지 확인이 필요합니다 — 요구한다면 ③④ 샘플의 레이아웃을 그 양식에 맞춰 다시 짜야 합니다.
  • 현장 시공 사진 1~2장 (참고용) 검증용
    이번에 추가한 사진대지 업로드 기능이 실제 현장 사진 비율·용량에서도 잘 보이는지 확인하기 위한 샘플입니다. 시스템 반영용이 아니라 테스트용입니다.

06

실제 구현 세부 단계

자료 의존도와 작업량 기준으로 4단계로 나눴습니다. 위로 갈수록 이미 끝났거나 바로 시작할 수 있는 일입니다.

Phase 0 — 완료

DONE

지난 세션에 이미 반영됨.

  1. 01사람 승인 게이트 시각 언어(잠금/체크, 배경 깜빡임) 전 화면 통일
  2. 02직원카드 프리셋 버튼 → 실제 처리 대상 주문 실행으로 연결
  3. 03원가대리 견적 → 조달몰 카탈로그 실단가 연동
  4. 04물류주임 사진대지 → 실제 파일 업로드

Phase 1 — 자료만 오면 바로 반영 (코드량 적음)

프론트엔드만

외부 API 없이, ①의 자료가 도착하는 대로 즉시 적용 가능.

  1. 05실제 단가표 반영 → Store.data.catalog 8개 항목 업데이트 (약 30분)
  2. 06회사 실제 정보 반영 → Store.data.settings 업데이트
  3. 07b2gDocsPage(orderId) 파라미터화 — 특정 주문의 서류가 항상 정확히 뜨도록
  4. 08CEO 결재: 견적 합계가 수의계약 한도(2,000만원) 초과 시 결재 버튼 차단
  5. 09비서실 일일 브리핑 — 오늘 완료/접수 건수 자동 집계로 초안 채우기

Phase 2 — 코드 + 소규모 리소스 필요

중간

API 키 발급 정도의 준비만 있으면 서버 없이도 가능.

  1. 10전화접수 원문에서 유형·부서·날짜 키워드 자동 추출 (규칙 기반)
  2. 11기상청 공공API로 시공일 강풍특보 자동 조회 (무료 API 키)
  3. 12⑤ 시안 목업에 제천시 CI 로고 실제 배치 (로고 파일 도착 시)

Phase 3 — 백엔드 필요 (별도 프로젝트 단위)

서버 필요

정적 HTML 한 장으로는 원천적으로 불가능한 항목. CLAUDE.md Phase 2 로드맵과 동일.

  1. 13홈택스 전자세금계산서 실발행 연동
  2. 14카카오 알림톡 실발송 연동
  3. 15AI 시안 이미지 실생성 (이미지 생성 API)
  4. 16사진 base64 → 실제 파일 스토리지 전환 (5MB 한계 해소)
